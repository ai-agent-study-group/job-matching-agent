# scraper

등록된 사이트·API에서 공고 원문과 출처 링크를 확보하는 공고 소스 어댑터를 위한 공간입니다.

Greenhouse·Lever의 공개 JSON API, Personio XML 피드, 범용 추출 방식 등을 조사합니다. MCP 도입 시 어댑터를 도구 뒤에 두고 agent가 검색·추출 도구를 호출하는 구조를 검토합니다. 현재 체크아웃에는 어댑터 구현이 없습니다.

사이트 목록의 등록 주체와 형식, 지원 소스와 실패 처리는 미정입니다. 기존 BE2 역할을 포함해 담당을 다시 정합니다.
