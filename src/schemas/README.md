# schemas

모듈 사이를 오가는 JD, 이력, 매칭 결과의 공통 Pydantic 스키마를 위한 공간입니다. 아래 항목은 초안이며 전원 합의로 확정합니다. 현재 스키마 구현은 없습니다.

| 스키마 | 필드 초안 |
| --- | --- |
| JD | 회사, 직무명, 원문 링크, 근무지, 필수·우대 요건, 기술 스택, 언어, 최소 연차 |
| 이력 | 경력 항목(회사, 기간, 역할, 한 일), 기술 스택, 언어 |
| 매칭 결과 | 요건별 판정과 근거 이력 항목, 점수, 언어·근무지·연차 필터 결과 |

PoC는 매칭 agent가 공고 원문을 읽습니다. 별도 JD 구조화 단계를 둘지는 추후 검토하며, JD 스키마 논의가 사전 구조화 구현 확정을 뜻하지 않습니다.

이력 직접 등록 형식, 소프트 요건 분리와 점수 표시 방식은 [스키마 안건](../../docs/meetings/2026-10-20.md#2-스키마)에서 정합니다. 초안 작성 담당도 역할 구분 후 배정합니다.
