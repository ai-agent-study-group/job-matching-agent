# llm

agent 실행과 도구 연결, 이력과 공고의 요건별 매칭·점수 산정을 위한 공간입니다. 현재 체크아웃에는 구현이 없습니다.

- PoC는 매칭 agent가 공고 원문을 바로 읽습니다.
- 요건별 충족·부분 충족·미충족과 근거 이력 항목, 점수, 언어·근무지·연차 필터 결과는 매칭 결과 스키마 초안입니다.
- 점수의 계산·표시 방식과 소프트 요건 분리는 회의에서 정합니다.
- JD 사전 구조화, 이력서 업로드·파싱과 대화 보충은 추후 검토합니다.

agent 구현·포트와 MCP 서버는 기존 역할표에 없던 작업입니다. 코드 위치, 구현 비교 방식과 담당자는 [10월 20일 안건](../../docs/meetings/2026-10-20.md)에서 정합니다.
