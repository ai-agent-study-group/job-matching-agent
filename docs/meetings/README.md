# 회의 기록

날짜별로 안건, 논의 메모, 결정 사항, 할 일과 미결 사항을 정리합니다.
정기 모임은 기본적으로 **매주 화요일 18:00**, **Discord**에서 진행합니다.

새 회의는 [회의록 양식](TEMPLATE.md)을 복사해 `YYYY-MM-DD.md`로 만들고 아래 목록에 추가합니다.
같은 날 여러 회의가 있으면 `YYYY-MM-DD-02.md`처럼 구분합니다.

| 날짜 | 회의 | 상태 |
| --- | --- | --- |
| 2026-10-20 | [10/20 회의 안건](2026-10-20.md) | 기록 중 |

- 회의 전: 날짜·안건을 작성합니다.
- 회의 중: 의견은 논의 메모에, 합의한 내용은 결정 사항에 기록합니다.
- 회의 후: 할 일의 담당·기한과 미결 사항을 확인합니다.

왼쪽 회의 폴더의 **새 회의록 작성** 버튼에서도 양식을 사용할 수 있습니다.
Markdown 회의록만 바꾸는 경우 PR은 선택 사항입니다.
