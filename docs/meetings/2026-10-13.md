## 기능 상세

### 1. 사용자 정보 수집과 통합 관리

- 1.1 이력서 파일 업로드 **[Phase 1]**: PDF·Word 등의 이력서에서 기본 데이터 추출.
- 1.2 입력 방식 다변화 **[Phase 2]**: 챗봇 대화, 스크립트·JSON으로 복합 경력 정보 입력·저장.

### 2. 채용 플랫폼 데이터 수집과 자동 탐색 [Phase 1]

- 2.1 외부 웹사이트 연동: 핵심 우선순위 공고 사이트 연동.
- 2.2 자동 탐색·수집: 에이전트가 최신 JD를 백그라운드에서 스크래핑·수집.

### 3. JD–이력서 매칭과 확률 분석 [Phase 1]

- 3.1 JD 요구사항 분석: LLM/AI로 필수 요건·우대 사항·주요 업무 추출.
- 3.2 적합도 산출: 이력서와 JD를 비교해 매칭 확률(%)과 적합도 계산.
- 3.3 우선순위 추천: 매칭률이 높은 공고를 선별·정렬해 사용자 화면에 제공.

### 4. 공고 맞춤형 이력서 수정·최적화 [Phase 2]

- 4.1 공고별 커스터마이징: JD 키워드·요구 역량에 맞춰 이력서 문장을 AI가 수정·강화.
- 4.2 맞춤형 이력서 생성·다운로드: 타겟 공고에 맞는 최종 파일 생성.
