MCP 서버는 새로 생긴 작업으로 기존 담당 표기에 대응하지 않습니다. 공고 검색도 agent가 도구로 수행하는 구조를 검토합니다. Gmail 알림 수집은 PoC에서 제외하며, JD 사전 구조화는 추후 검토합니다. 도메인(공통 데이터 형식)은 전원 합의 대상입니다.

직군별 메모·작업 내용·결정·참고 자료를 자유롭게 작성합니다. Markdown 문서와 문서용 이미지만 바꾸면 PR은 선택 사항입니다.
코드·사이트 화면·설정을 함께 바꾸면 [기여 규칙](https://www.google.com/search?q=https://github.com/ai-agent-study-group/job-matching-agent/blob/main/CONTRIBUTING.md)을 따릅니다.
