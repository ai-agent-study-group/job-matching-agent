# 디자인

germany-life-agent의 밝은 배경·네이비 텍스트·흰 카드·파란 강조색을 재사용합니다.
배경 #F8FAFC, 본문 #0F172A, 보조 #64748B, 강조 #3B82F6.
폰트는 시스템 한글 폰트를 기본으로 사용해 별도 CDN 없이 실행합니다.
카드는 24px 모서리와 부드러운 그림자, 4px 단위 간격을 사용합니다.
shadcn base-nova 설정, Base UI 버튼/텍스트 입력, Lucide 아이콘을 사용합니다.

홈은 설명→두 직무 분야 선택→매칭 흐름 순서입니다.
채팅은 모바일 단일 열, 데스크톱 채팅+안내 두 열입니다.
실제 AI 미연결 안내를 입력 전 보이게 유지합니다. 내부 코드 경로는 /admin 화면에만 표시합니다.
색상만으로 정보를 구분하지 않고 라벨을 함께 제공합니다. 입력·버튼에 접근 가능한 이름을 붙입니다.
