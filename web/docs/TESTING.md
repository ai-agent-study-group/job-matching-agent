# 수동 검증 체크리스트

화면·동작을 바꾼 뒤 커밋·PR 전에 직접 확인한다. 접근성 **코딩 규칙**은 [TECH.md](./TECH.md)의 "접근성(a11y)"이 단일 출처이고, 이 문서는 **확인 절차**다. (테스트 러너는 아직 미도입.)

## 반응형

- 모바일·태블릿·데스크톱에서 콘텐츠가 잘리거나 가로로 넘치지 않는지 확인한다.
- 기준 폭 예: **375px / 768px / 1200px**.

## 키보드·접근성 확인

- `Tab` / `Shift+Tab` 으로 조작 요소에 **순서대로** 접근되고, **현재 포커스가 눈에 보이는지** 확인한다. 키보드로 버튼도 실행해 본다.
- 현재 단계·오류 상태가 **색상뿐 아니라 텍스트로도** 구분되는지 확인한다.
- 비동기 로딩·오류 안내가 **보조 기술에도 전달**되는지 확인한다.

## 지원 브라우저

- 팀이 지원하는 브라우저에서 파일 선택, 입력 방식 전환, 이전·다음 이동, 결과 표시를 확인한다.
- **확인한 브라우저를 PR에 기록한다.**
